PORTAFOLIO PROFESIONAL Y LABORATORIO DOM

El sitio mantiene páginas HTML separadas para inicio, perfil, experiencia, formación, proyectos y referencias. El Laboratorio DOM está en laboratorio.html y conserva los controles interactivos requeridos en la consigna.

Abrir localmente: haga doble clic en index.html. El navegador requiere conexión a Internet para cargar Bootstrap 5.3 y la tipografía desde sus CDN. El CV en PDF está incluido en assets.

Publicar en GitHub Pages:
1. Cree un repositorio público vacío en GitHub.
2. Extraiga esta carpeta ZIP y cargue todos los archivos de la carpeta sitio en la raíz del repositorio.
3. En Settings > Pages, seleccione Deploy from a branch, la rama main y la carpeta /(root).
4. Guarde. GitHub mostrará la dirección pública al terminar la publicación.

Publicar en Netlify:
1. Extraiga la carpeta ZIP.
2. En Netlify, use Add new site > Deploy manually y arrastre la carpeta sitio extraída.
3. Netlify generará la dirección del sitio.
